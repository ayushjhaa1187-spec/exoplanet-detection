# exoplanet-ml Repo Notes
- **Purpose**: Reference for AstroNet and AstroWaveNet architectures.
- **Useful Folders**: `astronet/` (CNN implementation), `light_curve/` (binning and aggregation).
- **Setup Difficulty**: Medium/High. Uses Bazel and older TF versions.
- **What can be borrowed**: The "Global/Local" view concept, 1D CNN architecture parameters, binning math.
- **What should be ignored**: Bazel build files, legacy TF 1.x code structure.
- **How it fits the final system**: Provides the baseline model architecture and feature engineering logic.
