# PyTransit Repo Notes
- **Purpose**: Fast transit modeling using Numba.
- **Useful Folders**: `pytransit/` (models), `notebooks/`.
- **Setup Difficulty**: Low/Medium. Numba/OpenCL requirements.
- **What can be borrowed**: `RoadRunnerModel` for fast evaluation, limb darkening coefficients.
- **What should be ignored**: Transmission spectroscopy modules unless specifically needed.
- **How it fits the final system**: Scientific refinement layer for candidates identified by the CNN.
